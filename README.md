# Meu uArm - Controlador Android
Este projeto é um aplicativo Android desenvolvido do zero em Phyton, criado para interagir com o braço robótico **uArm Swift Pro**. O objetivo principal é fornecer uma interface simples e direta para comunicação e controlo do robô através de dispositivos móveis.

## 🚀 Funcionalidades Principais
* **Conexão Bluetooth:** Emparelhamento e comunicação direta sem fios com o uArm Swift Pro.
* **Monitorização em Tempo Real:** Indicador visual de estado que mostra instantaneamente se o robô está Desconectado (🔴) ou Conectando/Conectado (🟡/🟢).
* **Controlo de Movimento:** Interface limpa com um botão dedicado para enviar comandos de movimento ao braço robótico.
* **Pronto para IoT:** Estrutura base preparada para trabalhar em conjunto com o **Firebase Realtime Database** e scripts em Python.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **IDE:** Android Studio
* **Comunicação:** Bluetooth API do Android (com permissões atualizadas)
* **Backend/IoT:** Firebase Realtime Database
